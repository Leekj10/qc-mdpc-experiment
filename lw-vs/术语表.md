# 论文术语表

- **post-quantum cryptography (PQC)**（后量子密码）：专门设计成能抵挡将来大型量子计算机攻击的密码技术；在经典机器上运行。 → 本文里：本文研究 BIKE 这类后量子方案内部最关键的步骤：译码是否可靠。 ⚠ 易混：不是“量子密码/量子密钥分发”，后者靠量子物理分发密钥。
- **code-based cryptography**（基于编码的密码学）：用纠错码构造加密与密钥交换：合法接收者能纠错还原内容，窃听者面对的却是极难的译码问题。 → 本文里：BIKE 属于这一类，本文研究的正是它的译码核心。 ⚠ 易混：不等于一般“编码理论”。
- **error-correcting code**（纠错码）：在数据中按规则加入冗余，使一部分比特被破坏后仍能还原原文。 → 本文里：QC-MDPC 就是一种纠错码；译码即从被破坏的比特里找回错误模式。 ⚠ 易混：纠错码本身不等于加密，它不隐藏内容。
- **codeword**（码字）：满足全部校验规则的比特串，即译码器眼中的合法模式。 → 本文里：“近码字”“错纠”都以它为参照。 ⚠ 易混：不是“字符”，而是一个 0/1 向量。
- **parity check**（校验）：一条奇偶规则：某一组比特里 1 的个数必须是偶数，否则记为规则失败。 → 本文里：译码器每轮都数“有多少条规则失败”，据此决定翻哪些比特。 ⚠ 易混：与单个 parity bit 不同，这里是成组规则。
- **parity-check matrix H (H=[H0|H1])**（校验矩阵 H（两个循环块））：一张 0/1 表，每行规定一组参与同一校验规则的比特位置；在 BIKE 中它就是秘密密钥。 → 本文里：全文研究它的结构如何影响译码失败；H 还是配对实验的长期单元（每把密钥）。 ⚠ 易混：勿与生成矩阵混淆；两个块不是两套码，只是同一矩阵的两半。
- **QC-MDPC codes**（QC-MDPC 码）：准循环中等密度校验码：比特按圆环移位组织，每条规则覆盖中等数量的比特，密钥小而稀疏。 → 本文里：全文研究的码族，即 BIKE 的译码核心。 ⚠ 易混：与更稀疏的近亲 QC-LDPC 混用。
- **MDPC**（中等密度校验）：moderate-density parity-check：稀疏程度介于稠密与 LDPC 的极稀疏之间。 → 本文里：BIKE 码族名称来源；这种“不够稀疏”让相关攻击更难。 ⚠ 易混：与 LDPC 的密度和设计目标不同。
- **LDPC**（低密度校验码）：low-density parity-check：非常稀疏、用概率式消息传递译码、多用于通信纠错。 → 本文里：只在参考文献标题里出现，是 MDPC 的对照来源。 ⚠ 易混：与 MDPC 混用。
- **McEliece cryptosystem**（McEliece 密码体制）：1978 年最早的公钥加密方案之一，安全性建立在译码一类纠错码的困难性上。 → 本文里：只出现在参考文献标题；BIKE 属于这一传统的现代变体。 ⚠ 易混：与 RSA、格密码等其他公钥族。
- **quasi-cyclic / circulant block**（循环块）：一块 0/1 矩阵只由第一行决定，之后每一行都是上一行循环移位一格。 → 本文里：H=[H0|H1] 由两个这样的块拼成，密钥小、运算可用多项式表示。 ⚠ 易混：“循环”指行间移位，不是循环计算；移位不变性还导致近码字指纹需平移不变（README 记录过该 bug）。
- **block weight d**（块重）：每个循环块每行中 1 的个数。 → 本文里：局部模型用 Bin(d,p)；kappa 与 d 的大小决定捕获是否被排除。 ⚠ 易混：与错误重量 t 混用：d 描述码，t 描述错误。
- **r (block size)**（r（块长））：每个循环块的边长；主工作点 r=4801。 → 本文里：每个工作点坐标之一，也是 Misoczki 推荐参数的一部分。 ⚠ 易混：图里的 r1、r2、r2+ 表示“第1轮/第2轮/第2轮起”，与块长 r 无关。
- **t (error weight)**（错误重量）：被注入错误损坏的位置个数；主工作点 t=92。 → 本文里：第三个坐标，也是把失败率校准到可测带的杠杆。 ⚠ 易混：小写 t（错误重量）别与大写 T（迭代预算 20）混。
- **weight (Hamming weight)**（重量）：一个 0/1 向量中 1 的个数。 → 本文里：错误重量 t、块重 d 等核心参数都在数 1 的个数。 ⚠ 易混：与统计意义上的“权重”无关。
- **error vector e of weight t / error support**（重量为 t 的错误向量；错误支持集）：标明哪些位置比特被破坏（共 t 个）的向量；取值为 1 的位置集合叫支持集。 → 本文里：译码器看不到它，只能看到综合征；机制诊断需要真实错误支持，故属诊断专用。 ⚠ 易混：综合征是可见后果，错误向量是不可见起因；真实支持集是部署中拿不到的信息。
- **support (support set)**（支撑集）：一个 0/1 向量里取值为 1 的那些位置组成的集合。 → 本文里：近码字支撑、真实错误支持等说法都基于它。 ⚠ 易混：与日常“支持率”无关。
- **syndrome s = He^T**（综合征 s=He^T）：校验矩阵乘错误向量得到的 0/1 向量；全零当且仅当没有残余错误。 → 本文里：译码从初始综合征出发并每轮更新；配对实验让两臂共享同一个 s。 ⚠ 易混：综合征不等于错误本身：它由错误产生，不直接显示错误位置；零综合征也未必要等于找回真错误。
- **syndrome weight**（综合征重量）：当前失败的校验规则条数。 → 本文里：CLASSIC 阈值由它推出，局部模型也以它为条件。 ⚠ 易混：与错误重量不同：一个是失败规则条数，一个是错位个数。
- **F2 / mod 2 / XOR**（二元域/异或）：只用 0 和 1 的算术，加法不进位：1+1=0，即异或 ⊕。 → 本文里：综合征更新 s←s⊕H·1F 就是这种加法。 ⚠ 易混：与普通整数加法混淆。
- **F2[x]/(x^r-1)**（多项式环表示）：把二元循环矩阵写成多项式、x 的幂次代表移位、超过 r 次就绕回的代数设定。 → 本文里：实现里用它表示 QC-MDPC 运算，也解释循环块为何紧凑。 ⚠ 易混：括号里的 x^r-1 是回绕规则，不是减法运算。
- **parameter set (n,r,omega,t) / (r,d,t)**（参数集）：一套码的全部数字：n 为总比特数（=2r），r 为校验位数兼块长，omega 为每行总 1 数，t 为错误位数；按块写作 (r,d,t) 时 d=omega/2。 → 本文里：P1′、P2、P3、P4 以及 BIKE Level-1 都是这样的三元组。 ⚠ 易混：两套记号的字母含义不同，不能混读。
- **(n,r,omega,t) recommended parameter set (Misoczki)**（Misoczki 推荐参数集）：文献为 80 位安全级推荐的 (n,r,omega,t)=(9602,4801,90,84)。 → 本文里：主工作点保留其 (r,d) 并把 t 从 84 抬到 92：有文献背书的过驱点，不是随手代理。 ⚠ 易混：omega 是两块合计（=2d），不是单块重量；与 BIKE 生产参数不是一回事。
- **BIKE Level-1 parameters (12323,71,134) / native parameter set**（BIKE Level-1 原生参数集）：BIKE 最低档生产参数。 → 本文里：九百万次运行零失败的留出边界检验；只能给出非退化上界，非收益证据。 ⚠ 易混：与标定工作点 P1′–P4 不是一回事，也不可类比缩放。
- **security level (Level-1/3/5; 80-bit security)**（安全级）：用“破解大约需要 2 的多少次尝试”表示的强度档位。 → 本文里：80 位安全级的推荐参数集是主工作点来源；Level-1/3/5 调度用于验证重建。 ⚠ 易混：与本文的“证据分层 tiers”完全无关。
- **production parameters / production tail / cryptographic target**（生产参数/生产尾部）：实际部署所用的参数，以及真实系统必须达到的极小失败率。 → 本文里：本文结果在 1e-3–1e-4，远高于生产目标；论文明确不做生产尾部外推。 ⚠ 易混：与标定压力点混淆。
- **key-encapsulation mechanism (KEM)**（密钥封装机制）：一种公钥操作：在双方之间建立一个共享对称密钥；解封装可能失败。 → 本文里：BIKE 是 KEM，其解封装失败正是本文研究的 DFR。 ⚠ 易混：与公钥加密的接口和用途不同。
- **BIKE**（BIKE）：Bit Flipping Key Encapsulation：基于 QC-MDPC 码的后量子密钥封装方案，NIST 标准化进程第四轮候选。 → 本文里：全文围绕它的译码器（CLASSIC 载体）展开。 ⚠ 易混：本文的“规范精确”实现是自行重建，不是官方代码；不同规范版本细节不同。
- **BIKE specification v5.2**（BIKE 规范 v5.2）：BIKE 团队发布的正式规范，含参数与 BIKE-Flip 算法细节。 → 本文里：重建对照实现（仿射系数、整数阈值）的依据版本。 ⚠ 易混：与官方参考代码/官方常数不是一回事。
- **NIST post-quantum standardization process**（NIST 后量子标准化进程）：美国标准机构组织的多年公开遴选，选出抗量子算法。 → 本文里：BIKE 的出身背景；引 NIST 报告界定其现状。 ⚠ 易混：研究 BIKE 译码器不代表预测遴选结果。
- **IND-CCA**（IND-CCA 安全性）：很强的安全标准：即使攻击者能任选密文请求解密，也分辨不出挑战密文对应哪条消息。 → 本文里：论文声明自己不是 IND-CCA 证明。 ⚠ 易混：与只允许被动窃听的 IND-CPA 混淆。
- **implicit rejection**（隐式拒绝）：译码失败时不报错，而输出看起来随机的伪密钥，使攻击者分不清失败与成功。 → 本文里：BIKE 的保护手段；论文的 DFR 结论不否定它。 ⚠ 易混：与显式报错（explicit rejection）。
- **key recovery attack**（密钥恢复攻击）：目标是把秘密密钥或其结构算出来的攻击。 → 本文里：论文只刻画译码失败风险，不实施攻击、不做防御证明。 ⚠ 易混：与“恢复消息”的攻击不同。
- **reaction attack**（反应攻击）：利用受害方对输入可观察的“反应”（如是否解密失败）收集信息。 → 本文里：与计时、弱密钥并列的动机文献：失败行为会泄露结构。 ⚠ 易混：与功耗/电磁等物理侧信道不同。
- **timing attack**（计时攻击）：从操作耗时的差异推断秘密。 → 本文里：Eaton 等证明过 BIKE 的计时攻击；“常数时间约束”由此而来。 ⚠ 易混：与反应攻击（看结果而非耗时）。
- **weak key**（弱密钥）：结构上不幸的密钥：仍然保密，但译码失败频率远高于普通密钥。 → 本文里：全文动机；论文强调“弱密钥”涵盖多种不同机制，不可一概而论。 ⚠ 易混：不是弱口令或低熵密钥，不是“容易被猜出”。
- **gathering key**（gathering 密钥）：文献（Wang 等）定义的一类特殊弱结构密钥，与利用解密失败的“收集”式密钥恢复攻击相关。 → 本文里：论文只给出“与 gathering 相邻”的近码字可接受族证据，未构造精确的 gathering 密钥。 ⚠ 易混：作者特意把它与本文的“捕获”条件分开。
- **key-check mechanism**（密钥检查机制）：密钥投入使用前做检查、拒绝危险结构密钥。 → 本文里：Nosouhi 等路线：改变被接受密钥的总体，与“改变译码行为”互补。 ⚠ 易混：与生成阶段的结构过滤侧重点不同。
- **structural key filter**（结构化密钥过滤）：在密钥生成阶段就过滤掉结构不利的密钥。 → 本文里：与调度路线互补的另一条防御思路。 ⚠ 易混：与密钥检查机制混用（阶段与对象不同）。
- **error-feedback interface**（错误反馈接口）：系统的失败信息能怎样传回给攻击者的那条通路。 → 本文里：论文说 DFR 变化要转化为安全后果，需要部署参数、接口等条件匹配。 ⚠ 易混：与普通日志/报错接口。
- **distance spectrum**（距离谱）：描述合法码字之间相隔距离如何分布的结构指纹。 → 本文里：Guo 等证明译码错误会泄露它，这正说明失败率必须按密钥分别研究。 ⚠ 易混：与错误分布无关。
- **error floor**（错误平台）：失败率曲线在底部变平：条件再好也几乎不再下降的那一段。 → 本文里：近码字类方法针对的失效模式；论文声明自己不是错误平台防御。 ⚠ 易混：与“理论最小错误率”下限不同。
- **near-codeword**（近码字）：只违反极少几条规则的比特型样：看起来几乎像合法码字，但它不是。 → 本文里：NCW 条件、近码字感知译码器、捕获讨论的核心对象。 ⚠ 易混：与“码字”本身混淆；近码字是坏模式、是陷阱。
- **trapping set**（陷集）：一小撮比特与规则形成的局部结构，简单迭代译码器一旦陷入就出不来。 → 本文里：“为陷集设计的方法”即近码字类方法；是错误平台的常见成因。 ⚠ 易混：与近码字相关但强调“动力学困住”。
- **overlap kappa**（交叠量 κ）：注入错误与选定近码字共享的位置个数。 → 本文里：边界实验的梯度变量 κ=12/46/60；κ 超过 d 后 FRO-2 收益消失。 ⚠ 易混：与错误重量 t 混淆；κ 量的是重合，不是错误总数；也不是显著性水平。
- **bit-flipping decoding**（比特翻转译码）：每轮把“看起来最像错的”比特翻过来（0 变 1、1 变 0），直到所有规则通过或用完轮次。 → 本文里：本文全部译码器都是这一类，干预也只动它的阈值。 ⚠ 易混：与概率式消息传递译码不同：这里用整数计数加阈值。
- **parallel bit-flipping decoder**（并行比特翻转译码器）：每轮依据同一份当前状态一次性决定要翻的全部位置，而不是翻一个就更新一次。 → 本文里：所有对照臂都是并行式；这解释了失败轨迹总是跑满全部轮数。 ⚠ 易混：“并行”指同批决策，不是并行计算。
- **flip / flip set F / indicator 1F**（翻转；翻转集合 F）：把一个比特从 0 改成 1 或反过来；F 是本轮被翻位置集合，指示向量在其上为 1。 → 本文里：统计“翻对了几个、翻错了几个”是机制分析的基本量；更新 s←s⊕H·1F。 ⚠ 易混：翻一位不等于少一个错误——翻错会制造新错误；翻转集合不等于错误。
- **iteration / round**（迭代/轮）：译码器的一次完整循环：数规则、翻转、更新状态。 → 本文里：“首轮/第 2 轮/后续轮”就是本文的自变量。 ⚠ 易混：陷阱：与重复运行实验的“次”不同；也不是 NIST 那种遴选轮次。
- **iteration budget T**（迭代预算）：允许的最多轮数；用满仍未成功即判失败。主实验 T=20。 → 本文里：预算敏感性实验（7/10/20 轮）排除了“只是轮数不够”的解释；分类窗口 ceil(T/4)=5。 ⚠ 易混：不是计算超时，而是算法参数；T 与 t 不同。
- **threshold tau_i / first-round threshold tau_1**（阈值 τ_i）：一个比特所牵连的失败规则数要达到多少，才决定翻转它；tau_1 是首轮取值。 → 本文里：全文的自变量与机制核心：加 2、减 1 都作用在它上面。 ⚠ 易混：与门限密码学的“阈值”无关；tau 是整数计数，不是时间常数。
- **threshold rule tau(i,s) / threshold schedule**（阈值调度）：规定每一轮用多大阈值的规则，可随轮数或当前综合征重量变化。 → 本文里：本文的全部干预就是改变调度的一小部分。 ⚠ 易混：与操作系统的调度无关。
- **binomial threshold**（二项阈值）：用抛硬币式概率模型估计真实错误位平均牵连多少条失败规则，据此定出的阈值。 → 本文里：CLASSIC 载体的阈值来源，也是本文局部模型的基础。 ⚠ 易混：与固定阈值、仿射阈值相对。
- **affine threshold / affine coefficients / integer thresholds**（仿射阈值）：用“固定起点 + 固定步长×轮数”的直线公式给出的阈值，含公布系数。 → 本文里：BGF 与规范公式 BIKE-Flip 采用；其公布系数是 Level-1 的值。 ⚠ 易混：与二项阈值相对；系数错配不是算法本身的证据。
- **unsatisfied-parity-check (UPC) count u_j / U_{i,j}**（未满足校验数）：对某个比特位置，统计它参与的校验规则当前有多少条失败；取值在 0 到 d 之间。 → 本文里：翻转规则拿它与阈值比较；局部模型把它当二项量；诊断实验按它数翻转。 ⚠ 易混：不要与综合征重量混淆：后者是全码合计，UPC 是单点计数。
- **CLASSIC**（CLASSIC 译码器）：BIKE 套件中基线比特翻转译码器的专名：阈值由当前失败规则数的概率模型推出。 → 本文里：本文全部干预的载体、C0 所指对象。 ⚠ 易混：陷阱：不是形容词“经典的”，不要读成“传统比特翻转”的泛称。
- **first-round protection term**（首轮保护项）：BIKE-Flip 阈值公式里让第 1 轮更保守的一项。 → 本文里：说明“首轮更保守”的直觉已存在于生产译码器中；FRO-2 把这一直觉单独隔离验证。 ⚠ 易混：与 FRO-2 本身（单参数扰动）不同。
- **BIKE-Flip**（BIKE-Flip）：BIKE v5.2 里经过完整调优的生产译码器：阈值由高到低、含首轮保护项。 → 本文里：主要性能参照；因语义与调参不对等，论文不作支配性主张。 ⚠ 易混：本文是“规范公式”重建版本，不是官方实现；错配常数下的失败率不能当它的成绩。
- **BGF (black and gray passes)**（BGF 黑-灰两趟）：在仿射阈值之外再加“黑”“灰”两种不同激进程度的翻转趟的译码结构。 → 本文里：结构性参照之一：与 C0 统计不可分辨但每次译码多花约 22% 轮数。 ⚠ 易混：不是“黑白图片”；BGF-C3 不是官方调优版本。
- **BGF-C3 / GRAY_BGF**（BGF-C3（GRAY_BGF 结构 + CLASSIC 阈值））：本文的灰-BGF 实现：同一静态 CLASSIC 阈值加黑/灰子步，灰步参数固定为 3。 → 本文里：公平的结构参照：与 C0 不可分辨、成本更高；论文强调它不是官方 BGF 结果。 ⚠ 易混：“C3”指灰步增量=3，未在正文写出；勿当官方 BGF 基准。
- **BF-Max**（BF-Max）：每轮只翻“计数器最大”的一个位置（并列随机打破）的译码器。 → 本文里：用于核对重实现与已发表算法一致（并列处理）。 ⚠ 易混：与阈值式比特翻转、与 BF30 不同。
- **BF30**（BF30（固定阈值 b=30））：朴素并行比特翻转，固定阈值 b=30，在筛选点 P1 使用。 → 本文里：随机化负对照的固定载体：抖动让 DFR 从 4.29% 升到 19.7%–50%+。 ⚠ 易混：与 CLASSIC（自适应阈值）不同；30 是阈值值，不是调优结果。
- **Backflip**（Backflip）：保存有限历史、允许按存活时间撤销先前翻转的译码器。 → 本文里：动态语义下最强参照：100 万次零失败，说明 FRO-2 不是所测最强译码器。 ⚠ 易混：其比较是语义参照下的，不是同语义对决。
- **near-codeword-aware decoder**（近码字感知译码器）：能识别“当前综合征已接近某个近码字”，并整块翻转该近码字全部 1 位置的专门译码器（Baldelli 等算法 2）。 → 本文里：结构对照：κ<d 时完全惰性（0 次触发），κ=46 时决定性起作用（11.07% 对 85.31%），证明两类干预机制不同。 ⚠ 易混：与 NCW-shallow（条件）和 SR-NCW（恢复原型）不是一回事。
- **decoding failure rate (DFR)**（解码失败率）：所有译码尝试中最终没有成功的比例；成功判据是综合征归零。 → 本文里：本文的主结果指标，全部在约 1e-4–1e-3 处测量。 ⚠ 易混：是译码失败不是解密失败；生产 BIKE 目标接近 2^-128，本文数值是刻意的可测点，不是安全级数。
- **conditional DFR**（条件 DFR）：只在某个特定条件与某条臂内计算的失败率，而不是全体平均。 → 本文里：全文重建指标的方式：平均值会掩盖“少数密钥特别糟”。 ⚠ 易混：陷阱：不是对单把密钥的条件化，也不是贝叶斯条件概率。
- **zero syndrome (success criterion)**（零综合征（成功判据））：所有规则都通过时译码器宣告成功；此时残余差至少是一个码字，未必等于真错误。 → 本文里：主研究用它判成功，审计再检验更强的“精确恢复”以排除骗人的成功。 ⚠ 易混：零综合征与找回真错误只是经验上一致，逻辑上不等价。
- **exact-recovery audit**（精确恢复审计）：用译码器全部翻转的奇偶性重建它估计的错误，再与真实错误比对；译码器本身看不到真值。 → 本文里：排除零综合征错纠：C0 的 795 与 FRO-2 的 167 次失败与零综合征总数一一吻合，错纠为 0。 ⚠ 易混：这是审计不是攻击；结论是经验一致而非定理。
- **zero-syndrome miscorrection**（零综合征错纠）：所有规则都通过（看起来成功），但得到的答案其实是错的。 → 本文里：若大量存在会虚增 FRO-2 的胜绩；双臂实测均为 0。 ⚠ 易混：0 次只是对 170 万次译码的经验上界，不是不可能性证明。
- **failure taxonomy / failure-mode classifier**（失败分类/失败模式构成）：把每次失败按可观察的轨迹特征归入命名类别（停滞、早期误翻、发散、周期 2 等）。 → 本文里：报告停滞为最大类（如 RAND 的 C0 失败 198/282）；分类器窗口曾修补过。 ⚠ 易混：模式计数描述失败的构成，不是失败率；在失败内部归一化。
- **stagnation**（停滞）：译码器原地打转：既纠不完错误，也不再继续好转。 → 本文里：最大的失败类别；STLR 的触发条件；也是局部模型警告的两种坏结局之一。 ⚠ 易混：是动力学停滞，不是“轮数不够”。
- **cascade**（级联）：一轮翻错引发下一轮更多翻错的恶性连锁。 → 本文里：模型预测 FRO-2 降低进入级联或停滞的概率。 ⚠ 易混：与停滞是两种不同失败轨迹；也不是字面测到的“盆”。
- **early misflip**（早期误翻转）：错误翻转发生得很早（前四分之一窗口内），由此定下后续败局。 → 本文里：第二分类类别；其窗口定义的档案分歧最终被证明是空操作。 ⚠ 易混：预注册窗口是 ceil(T/4)；档案分类器用翻转数的四分之一——此数据上两者巧合一致。
- **misflip window (|flips|/4 vs ceil(T/4))**（误翻转窗口）：“早期”的两种定义：已记录翻转数的四分之一，或迭代预算的四分之一向上取整。 → 本文里：按预注册定义重跑：30 个格子全部相同；原因是失败轨迹总是跑满预算。 ⚠ 易混：一致是构造使然，不是新证据。
- **correct vs incorrect flip / first-round flip accounting**（正确翻转/错误翻转；首轮翻转账目）：翻的是真正被破坏的比特（好）还是完好比特（坏）；账目即逐实例统计首轮两类翻转数。 → 本文里：全文最关键的不对称：FRO-2 把错翻转降约 9.5 倍，对翻转只降约 2.7 倍（8→0.8 对 29→9）。 ⚠ 易混：标注翻转需真错误支持，属诊断工具，不是可部署信号。“错误翻转”不是“翻转没执行”。
- **residual error weight**（残差错误重量）：某一时刻还剩多少个比特没有纠正。 → 本文里：FRO-2 首轮后残差反而更大（约多 6 位）——论文借此强调“即时残差小”不是好调度的目标。 ⚠ 易混：残差大但后续可能全部回收，与最终失败不同。
- **deferred corrections**（被推迟的修正）：FRO-2 把部分正确翻转推迟到后续轮次；后续轮从更干净的支持配置里收回它们。 → 本文里：机制的另一半：FRO-2 不是早修得多，而是让后轮继承更少污染的状态。 ⚠ 易混：推迟不是遗漏，错误后来确实被纠正。
- **over-flipping / under-flipping**（过度翻转/翻转不足）：阈值太低导致乱翻失控，或阈值太高导致几乎不翻而卡住。 → 本文里：随机化负对照的机制解释：抖动把译码器推向这两侧。 ⚠ 易混：两者常被笼统说成“调参不好”。
- **threshold cliff**（阈值悬崖）：阈值只要稍微改变，失败率就剧烈变化的狭窄区间。 → 本文里：论文用它排除“只是把工作点移离悬崖”的解释——全局 +2 反而摧毁译码器。 ⚠ 易混：悬崖是阈值响应曲线的性质，不是密钥的性质。
- **safe band (viable threshold band)**（安全带）：阈值仍能正常工作的取值区间；越界则过度翻转或翻转不足。 → 本文里：解释随机化为何失败（采样落在带外）而精确定时的确定性偏移成功。 ⚠ 易混：带窄意味着对阈值做平均化推理会误导。
- **capture / dynamical capture basin**（捕获/动力学捕获盆）：译码器一旦进入就逃不出来、只能走向失败的状态区域。 → 本文里：κ>d 被称为“捕获倾向”压力测试，但论文明确声明没有验证真正的捕获盆（未记录终局轨迹距离或盆内比例）。 ⚠ 易混：高失败率本身不是捕获盆的证据——论文两次强调。
- **capture-prone / kappa > d**（捕获倾向（κ>d））：错误与近码字交叠数 κ 超过块重 d 的情形；译码可能被拉进近码字盆地，无论怎么调阈值都可能失败。 → 本文里：论文的尖锐边界：κ=46 处 FRO-2 近乎无效（RR 0.986）；论文拒绝把它称作已证实的捕获盆。 ⚠ 易混：陷阱：不要把 capture-prone 等同于 NCW-shallow，这一等同正是论文要避免的。
- **threshold randomization / coin-selected variants**（阈值随机化/掷币式变体）：用随机掷币变动阈值：围绕基准抖动，或随机挑一条调度。 → 本文里：负对照：在 BF30 上惨败，在 CLASSIC 上未分辨，正式搜索中没有掷币候选存活。 ⚠ 易混：结论只限所测设计空间里的无结构混合，不否定一切随机化译码器（论文引用原地/有状态方法作对照）。
- **jitter (symmetric / positive-only)**（抖动）：每轮给固定阈值加随机扰动，或对称双向 {-1,0,+1}，或仅正向 {0,+1,+2}。 → 本文里：在 BF30 上两种变体把 DFR 抬到 19.67% 与 50%–52%。 ⚠ 易混：扰动幅度小不等于影响小——安全带很窄。
- **convergence iterations / two-round convergence / mean iterations**（收敛迭代数/两轮收敛率/平均迭代数）：成功译码用了多少轮；生产尺度上用作可测信号的是“两轮内收敛的比例”。 → 本文里：FRO-2 平均多花约 0.25–0.28 轮；Level-1 两轮收敛从 96.0% 降到 68.4%（+2）、2.2%（+4）。 ⚠ 易混：收敛快不等于正确率高；这里它是成本，论文如实说。
- **budget exhaustion / budget-exhaustion rate**（预算耗尽率）：用满全部迭代预算仍未成功的比例。 → 本文里：主实验预算 20；7/10/20 都保住效应；预算 20 区间偏宽是因为部分重抽样里 FRO-2 零失败（如实报告）。47.9% 的耗尽率只用于暴露常数错配，不是 BGF 的成本。 ⚠ 易混：高耗尽率可能反映常数不对而非算法不好。
- **simulation-privileged / diagnostic instrumentation**（仿真特权；诊断性仪器）：使用了真实部署中拿不到的信息（如真实错误或到它的距离），仅用于解释；不是可部署的决策信号。 → 本文里：动态语义与翻转诊断都属此类；9.5 倍/2.7 倍等机制数字的性质由此界定。 ⚠ 易混：陷阱：与“特权用户”无关；也不是作弊，是有意为之的参照语义。
- **static vs dynamic-distance threshold semantics**（静态/动态距离语义）：阈值公式是用事先已知的名义错误重量（静态），还是被允许参考当前估计与真实错误之间的距离（动态）。 → 本文里：主研究是静态；C 参考与 Backflip 比较是动态，效应持续但缩小（1.59 倍、2.01 倍），NCW 变得未分辨。 ⚠ 易混：陷阱：“静态”不指综合征静止；动态语义用了真实部署没有的信息，两种语义的数字不能直接比。这是论文最明确警告的混用。
- **risk ratio (RR)**（风险比）：对照组的失败率除以干预组的失败率。 → 本文里：全文主效应量（如 4.15、5.47）。 ⚠ 易混：陷阱：方向与临床用法相反——RR 大于 1 有利于新调度（因为分子是 C0），“区间排除 1”表示两臂有别。与优势比、相对风险减少也不能混用。
- **x-fold reduction**（降低 4.15 倍（比值表述））：比值表述：降低 4.15 倍意味着新值约为旧值的四分之一。 → 本文里：摘要与结果用这种说法给主效应（4.15–5.47 倍；翻转类型 9.5 倍对 2.7 倍）。 ⚠ 易混：陷阱：是除法不是减法——不是“减少了 4.15”，也不是“降到 4.15%”。
- **absolute DFR difference**（绝对 DFR 差）：两个失败率直接相减，以百分点为尺度的效应。 → 本文里：作为次要结果报告，区间排除 0；与比值互补，因为极小率上的大比值可能只是极小的绝对变化。 ⚠ 易混：比值与绝对差可能给出不同的实际重要性，论文有意都报。
- **odds ratio (schedule odds ratio)**（优势比）：优势之比而非率之比，比较两条调度下失败的优势。 → 本文里：由 beta-二项敏感性模型给出（0.241、0.183、0.220），区间都排除 1。 ⚠ 易混：优势比离 1 更远，且方向看似相反：OR 小于 1 有利于 FRO-2，而 RR 大于 1 有利于 FRO-2。
- **confidence interval (95%)**（95% 区间）：未知量的一个合理取值区间，按重复实验 95% 覆盖真值的方式构造。 → 本文里：每个主效应都以 RR 加 95% 区间报告，作为决策辅助（是否排除无效值）。 ⚠ 易混：不是“真值落在本区间内的概率为 95%”；本文若干区间是单侧的或延伸到无穷。
- **interval excludes one / interval excludes zero**（区间排除 1 / 区间排除 0）：比值型区间不含 1、差值型区间不含 0，表示在该置信水平上效应可分辨。 → 本文里：论文反复出现的显著性说法，对约 50 个比值区间总限定为“逐对比”。 ⚠ 易混：众多区间中偶发的排除是期望之内的，论文拒绝做联合覆盖声明。
- **one-sided versus two-sided**（单侧／双侧）：单侧只朝一个方向作陈述（上界，或只检验变差）；双侧允许两个方向。 → 本文里：Wilson 上界是单侧，符号检验是双侧；工程区间保留无穷后成为单侧。 ⚠ 易混：别机械搬用：“首轮是双向窗口”指两个方向的危害，不是统计检验。
- **marginal intervals vs simultaneous coverage**（边际区间；联合覆盖）：每个区间单独是对一个比较的 95% 陈述；数十个合起来没有整族的 95% 联合保证。 → 本文里：约 50 个 RR 区间未校正；只有一张表做多格主张并明确标注。 ⚠ 易混：陷阱：逐对比显著不等于族显著性；“每个区间都排除 1”读作联合声明会强得多。
- **p-value / significance**（p 值；显著）：若真无效应，看到至少同样极端数据的概率；越小越像有证据反对“无效应”。 → 本文里：主表等处报 Holm 校正后的 p；论文更依赖区间与操作门槛而非星号。 ⚠ 易混：p 值不是效应为真的概率；显著不说明效应大小；探索性格子不用它评判。
- **exact two-sided sign test (per-key)**（精确双侧符号检验）：逐把密钥比较两臂失败数，只数“哪边更好”并检验对比是否一边倒得超出偶然。 → 本文里：278 把中 233 更好、18 更差、27 持平；三条件经 Holm 校正。 ⚠ 易混：它忽略差值大小并剔除持平；检验方向一致性，不是率差大小。
- **exact McNemar test**（精确 McNemar 检验）：针对同一实例上两种方法的成败配对，只利用两者不一致的那些实例。 → 本文里：实例级配对检验（如同 (H,e,s)），Holm 校正；也判定 FRO-2 与 BIKE-Flip 的持平（p=0.228）。 ⚠ 易混：不是独立两样本检验；它在实例层面，符号检验在密钥层面。
- **Fisher's exact test**（Fisher 精确检验）：小样本下对 2x2 表精确计算概率，而不用大样本近似。 → 本文里：用于小的 CLASSIC 阈值随机化探针，Holm 校正后什么都不显著（p 至少 0.54）。 ⚠ 易混：那里的不显著报告为“未分辨”，不是“随机化无效”的证据。
- **Holm adjustment**（Holm 校正）：一次做多个检验时逐步收紧每个结论，控制“总体中至少出现一次误报”的概率。 → 本文里：作用于三个正式条件的符号与 McNemar 检验，以及负对照 Fisher 检验。 ⚠ 易混：它不覆盖约 50 个 RR 区间；“一个校正保护一切”是最常见的误读。
- **z statistic (two-proportion)**（z 值）：两个观测比例的标准化差异，除以自身不确定度；绝对值越大越难用偶然解释。 → 本文里：跨实现一致 z=-0.68（落在预设带内）；范围检查 z=7.94、11.98（可分辨）与 1.36（NCW，未分辨）。 ⚠ 易混：z 不是效应量，随样本量增大；带内只表示未检出分歧，不是实现完全一致。
- **Wilson upper bound**（（单侧 95%）Wilson 上界）：在只有有限次试验时，对真实比例给出的保守上限公式，少量失败时仍稳健。 → 本文里：所有非零失败格都报单侧 95% Wilson 上界；它也是筛选判据与图上帽线。 ⚠ 易混：不是点估计——上界比点估计更保守；也不低于零。
- **rule of three (3/N bound)**（rule-of-three 上界（3/N））：N 次试验一次失败都没出现时，失败率的粗略 95% 上限约为 3/N。 → 本文里：零失败单元（BIKE Level-1 九百万次、Backflip、生产留出）的上界来源。 ⚠ 易混：零失败只能给上界，绝不能被读成“零风险”，也不是收益证据。
- **zero-count convention / continuity correction**（零计数约定；连续性修正）：对零失败格声明一条规则（报 3/N），而不是悄悄给计数加小数以避免零。 → 本文里：全文统一使用，不引入隐式连续性修正，零格在各表间行为可比。 ⚠ 易混：软件里给零格加 0.5 会给出略不同的区间；本文的约定更简单也更保守。
- **cluster bootstrap (key-cluster bootstrap interval)**（密钥聚类自助法）：以整把密钥为单位有放回重抽 10000 次，且保留该密钥的全部错误，重算效应得到误差范围。 → 本文里：所有主区间的构造方法（种子 20260905），也是“以密钥为再抽样单元”这一方法论主张的核心。 ⚠ 易混：不是对单条错误样本重抽；抽到某密钥就带上它全部错误，尊重钥内相关。
- **resampling unit**（再抽样单元）：重抽样程序重新抽取的实体；这种单元的量决定不确定度的真实分辨率。 → 本文里：全文方法论中心：92–94 把密钥×3000 错误提供约 90 个密钥级单元，而不是 834,000 个独立观测。 ⚠ 易混：同一把密钥的数千条错误不是数千个独立观测，而是同一单元的相关重复。
- **key-conditional risk / inference clustered by key**（密钥条件风险；以密钥为聚类单元的推断）：把每把秘密密钥（而非每条错误样本）当作会变化、可独立重抽的单元：同一密钥下的错误是相关重复。 → 本文里：论文自称的新意与标题定位：结果在密钥层面合并、配对、重抽样。 ⚠ 易混：不是只分析一把密钥；一把密钥的全部错误都用上，只是按相关而非独立处理。
- **infinite bootstrap replicate (zero-failure replicate)**（无穷重抽样）：重抽样数据里某条臂零失败时比值变成无穷；把这种重抽样丢掉会让区间显得比实际窄。 → 本文里：受影响的工程格（P3/NCW 丢弃最高 36.8%）已保留无穷重抽并重推，相关区间因此成为单侧、上端为无穷。 ⚠ 易混：只用有限重抽样构造的区间会低估不确定性；论文要求把那些格视为延伸到无穷。
- **beta-binomial model**（beta-二项模型）：允许每把密钥围绕共同平均有自己的失败率的概率模型，钥间差异可超出纯抽样噪声。 → 本文里：敏感性分析给出调度优势比与钥间差异检查；差异近零时退化为合并风险比，仅作方向性检查。 ⚠ 易混：它更窄的区间随后是模型产物，论文拒绝把它当作独立的精度陈述。
- **overdispersion (intra-key overdispersion)**（过度离散）：钥（或钥内）差异大于随机抽样模型所能解释的额外变动。 → 本文里：拟合值在可分辨度下与零无异（p≈0.49），这也支持使用密钥聚类自助法。 ⚠ 易混：零过度离散不等于密钥相同，只是此数据在此计数下测不出钥间差异。
- **P90-P10 span (heterogeneity criterion)**（P90–P10 跨度）：密钥间失败率分布的第 90 与第 10 百分位之差。 → 本文里：原拟的异质性判据需至少 3 个 log10 单位，实测 0.40–0.48，未达成，论文如实报告。 ⚠ 易混：未达成不证明密钥同质，只说明该池按此尺子不够异质；也与极差（最大减最小）不同。
- **sensitivity analysis / sensitivity result**（敏感性分析/敏感性结果）：在其他子集或假设下重查结论是否存活的附加检查。 → 本文里：全池对纯新门槛、beta-二项模型、预算与目标重量扫描、动态语义重跑都属此列。 ⚠ 易混：敏感性结果不是替代性主结果；两者分歧时论文写明哪一个是判据。
- **confound**（混淆）：两个差异一起动，导致无法分清各自的作用。 → 本文里：全局偏移对首轮偏移的对比把位置与持续性混在一起，催生了轮次对照臂；共用一个密钥池避免工作点混淆。 ⚠ 易混：混淆是设计问题不是代码错误；补救是加臂而不是调分析。
- **round controls / round-controlled ablation**（轮次对照/带轮次对照的消融）：只改变偏移施加在哪一轮、保持偏移值不变的一组附加实验臂，用以把位置与持续性分开。 → 本文里：化解了原设计中全局与首轮对比的混淆，产出论文的核心分离结论。 ⚠ 易混：它们是事后追加而非预注册，论文明确说明；消融谈机制归因，不是性能排名。
- **temporal ablation / temporal dissociation**（时序消融/时序解离）：同一个 +2 偏移放进不同轮次导致相反命运的实验及其实验图（图 4）。 → 本文里：图 4 被称为因果核心：首轮有益、仅第 2 轮略有益、持续则有破坏性。 ⚠ 易混：消融变的是施加时机，不是偏移大小。
- **negative control**（负对照）：一个预期看不到收益的臂，用来证明正结果不是测量布置或噪声的产物。 → 本文里：阈值随机化即负对照：在固定阈值载体上把失败率从 4.29% 抬到 19.67%，且在 CLASSIC 上未分辨。 ⚠ 易混：CLASSIC 探针未分辨（p 至少 0.54）不能当随机化的正结果；结论锚在 BF30 载体上并限定了范围。
- **comparator (matched vs out-of-tuning; dominance)**（比较器；支配性）：被新方法对照的参照方法；只有设置合适、语义相同时比较才公平。 → 本文里：BIKE-Flip、BGF-C3、Backflip 都是语义与调参不对等的参照；规范精确的重建因常数错配在 P1′ 就失败 38%–60%。 ⚠ 易混：击败或打平一个比较器不构成支配性主张，论文明确拒绝这种读法。
- **paired (H,e,s) instance / paired control**（配对实例/配对对照）：两条臂处理完全相同的密钥、错误与综合征；每个配置称为一条臂，配对消除样本难度混杂。 → 本文里：配对是设计要件，也是逐实例 McNemar 检验的许可条件。 ⚠ 易混：配对控制了实例难度但不处理密钥聚类；两者都要，论文都做。
- **arm**（臂）：同一批实例上运行的一种译码配置（如 C0、FRO-2、STLR）；结果按臂报告。 → 本文里：表中计数都以臂为单位；样本量如每臂 834,000 个观测。 ⚠ 易混：臂是调度配置，不是一组密钥；每条臂看到的密钥与错误完全相同。
- **condition / condition group**（条件/条件组）：三种密钥与错误构造之一：RAND、TYPE-I、NCW-shallow；“最差条件组”指三者中最不利者。 → 本文里：门槛定义在最差组上（刻意用最坏情形而非平均）；符号与 McNemar 在三条件间做 Holm 校正。 ⚠ 易混：此处的“条件”是实验制度，不是条件概率的条件。
- **cell**（单元/格子）：一个（工作点，条件）组合，如 P2/RAND；大多数表出现 6 个格。 → 本文里：论文统计“几个格的区间排除 1”（如 FRO-2 对 STLR 为 0/6），主张的宽度以格为限。 ⚠ 易混：各格不是独立样本；同一密钥跨格重复出现，多格主张明确不是联合覆盖。
- **statistically resolved / unresolved / underpowered / tied**（可分辨/未分辨；功率不足；持平）：数据能否把两者区分开；持平指在此样本量下检不出差异。 → 本文里：防过度声称：动态语义 NCW（z=1.36）与稀疏格未分辨，12 密钥矩阵功率不足，RAND 对 BIKE-Flip 持平（p=0.228）。 ⚠ 易混：未分辨与持平不是“无效应”，而是本设计分辨不了，故每个主张都附样本量。
- **population-average risk**（总体平均风险）：在抽样得到的密钥总体上取平均的失败率。 → 本文里：TYPE-I 构造明确不用于估计它；只有 RAND 式抽样能谈总体，且仅对被测生成器。 ⚠ 易混：平均风险与最差组风险可能不一致；门槛刻意用最差组。
- **cross-implementation validation**（跨实现验证）：用两份分别编写的程序跑同一实验，检查结果不是编码假象。 → 本文里：Python 与 C 参考在 RAND 与 Type-I 上复现计数（11/20000 对 136/200000）与方向，NCW 未分辨。 ⚠ 易混：两个程序同属一个项目：这检查实现一致，不是独立实验室可重复性。
- **replication (internal vs independent)**（复现（项目内/独立））：重复结果：同队重复检验一致性，他处重复检验可推广性。 → 本文里：效应在更大的码与第二个工作点复现；外部盲复现列为未来工作。 ⚠ 易混：可复现（同数据同码得同数）与可重复（新数据得同结论）是不同的保证。
- **predeclared consistency band**（预设一致带）：事先固定两实现允许差多少才不算分歧的容差。 → 本文里：z=-0.68 落入带内，两实现被判一致。 ⚠ 易混：它是务实的协议带，不是 95% 置信区间。
- **operational gate (0.5 log10, non-degradation)**（操作门槛）：事先定好的通过标准：最差条件组的保守上界至少改善 0.5 个以 10 为单位的量级，且随机组不退化。 → 本文里：纯新子集 0.687 通过（约 4.9 倍）；全池 0.679 仅敏感性；P2 迁移点 0.384 未达标但方向一致。 ⚠ 易混：它明确不是形式化非劣性检验；0.5 是 log10 单位，不是百分点。
- **worst-group log-upper-bound improvement**（最差组对数上界改善）：三个单侧 DFR 上界中最大（最差）者的以 10 为底对数，在两臂间的差。 → 本文里：门槛的量：纯新 0.687、全池 0.679、P2 处 0.384。 ⚠ 易混：用上界不用点估计，因此偏保守；不是点估计之比。
- **non-degradation constraint (random group)**（非退化约束）：要求改进不能以随机键组变差为代价。 → 本文里：防止某调度靠牺牲随机键换取最差组通过；正式运行中 RAND 满足。 ⚠ 易混：是单侧要求，不是相等性检验。
- **evidence tiers (confirmatory / exploratory / feasibility; Table I)**（证据分层）：按实验规模与可得出的结论强度给证据分级：一级正式主实验与控制、二级预注册确认、三级探索性消融、四级原型工程。 → 本文里：表 1 规定三、四级结果一律标注探索性或原型级，不参与主结论。 ⚠ 易混：层不是样本量，而是推断权限；大规模探索跑仍是三级。与安全级无关。确证性不等于外部实验室复现。
- **successive halving / candidate screening**（逐次减半/候选筛选）：先用少量数据廉价测试许多候选，每轮保留更好的那一半、淘汰其余。 → 本文里：从 9 个调度中筛出 FRO-2；按最差条件组的单侧 95% 上界保留候选，并施加随机组非退化约束。 ⚠ 易混：通过筛选不是通过形式化检验；“不使随机组退化”的附加条件容易被忽略。
- **preregistered**（预注册）：在看到数据之前就把方案、指标与通过门槛写死，使分析不能按结果挑选。 → 本文里：0.5 log 门槛与纯新子集是预注册判据；扩大的确认（种子 20260912）与失败分类器也是预注册定义。 ⚠ 易混：只有部分分析是预注册的；轮次对照臂等明确是事后或探索。与安全级、与“预设”都不等同。
- **prespecified / predeclared**（预设/预规定）：在项目内事先固定、在相关运行前冻结；比正式注册稍弱。 → 本文里：P2 迁移运行、操作门槛、偏移选择规则、跨实现一致带都称预设或预规定。 ⚠ 易混：预设不等于预注册，两者都不保证分析在看结果前是合理的；论文坚持区分层次。
- **post hoc**（事后追加）：看到数据或发现问题之后才补做的分析。 → 本文里：两个决定性的轮次对照臂是事后追加：全规模报告，但标注为未预注册、单一工作点。 ⚠ 易混：事后不等于无效；论文把它们当作真实结果但排在预注册确认之下。
- **pure-fresh subset**（纯新子集）：未参与任何中期筛选决策的 212 把密钥，每臂 636,000 个观测。 → 本文里：预注册门槛 0.687 的判定依据；全池值只作敏感性报告。 ⚠ 易混：不是 P4 的 48 把留出密钥，也不是 P2/P3 的重生成密钥——本文有三个不同的“留出”。
- **held-out / holdout**（留出）：事先搁置、只在最后检验时使用的数据或工作点。 → 本文里：P4 从未参与开发；48 把新密钥构成留出验证；Level-1 是生产边界留出。 ⚠ 易混：本文有三种留出，回答不同问题（程序有效性、中期复用、生产边界），论文警告不要合并。保证只是“未用于中期决策”，不是随机切分。
- **interim pool / interim reuse**（中期池；中期复用）：开发期间已被查看过的密钥或错误；复用会削弱后续确认，因为早先的选择已对着它们调过。 → 本文里：这解释了为何全池只能当敏感性、纯新子集才是门槛；探索种子与确认种子严格分开。 ⚠ 易混：复用不是不端行为，但复用数据与新鲜数据的证据强度不同，论文如实分级。
- **formal pool**（正式池）：全部正式密钥：92 RAND + 94 TYPE-I + 92 NCW-shallow = 278 把，各配 3000 条错误，每臂 834,000 个配对观测。 → 本文里：主分析样本；纯新子集从中划出，门槛判在子集而非全池上。 ⚠ 易混：它扩展自一个中期池，并非完全独立，故其 0.679 只是敏感性结果。
- **key family / key batch**（密钥族/密钥批次）：按构造规则划分的一批密钥（随机、RUN-12/TYPE-I、近码字可接受）；固定错误构造、只变密钥族。 → 本文里：密钥族分析（RR 4.17/4.44/4.33）表明收益不限于某种构造，且仅凭准入不产生浅交叠效应。 ⚠ 易混：“族”按构造分组；“批次”是族的一次具体实例。
- **error pool**（错误池）：为一批密钥生成的全部错误样本的集合。 → 本文里：两臂必须共享同一错误池；在不同池上比较会把调度效应与样本难度混在一起。 ⚠ 易混：池错误不是池密钥；再抽样单元是密钥，永远不是错误抽取。
- **whole keys assigned (split at the key level)**（整把密钥分配）：按密钥而非单条错误把数据分给搜索、验证与测试阶段；一把密钥不跨阶段。 → 本文里：防止测试密钥的部分错误曾影响调度选择的泄漏，是“密钥为再抽样单元”的设计对应物。 ⚠ 易混：不是实例级交叉验证；本文不用实例级划分。
- **operating point / calibrated operating point**（工作点）：一次实验所选的 (r,d,t) 组合（如 P1′=(4801,45,92)），经标定使失败率恰好可测。 → 本文里：所有结果按工作点组织；P4 是留出验证点。 ⚠ 易混：是测量设置，不是生产参数集，也不是统计学的“点估计”。
- **over-driven / calibrated pressure point**（刻意过驱；标定压力点）：故意把错误数加到推荐值之上，使对照译码器的失败率高到可被测出。 → 本文里：P1′ 保留 Misoczki 推荐的 (r,d) 并把 t 从 84 抬到 92——有文献背书的过驱点，不是随手代理。 ⚠ 易混：“压力”不是攻击压力，而是为可测性施加的仿真压力；也与参数调优不是一回事。
- **measurable band / knife-edge operating points / measurable window**（可测带；刀刃状工作点）：基线失败率既不低到数不出、也不高到两臂全败的狭窄难度区间。 → 本文里：t 约 90 以下基线几乎不失败，高 t 格饱和；只有 13%–54% 失败的格可分辨，未命中作为结果如实报告（12 个格中 6 下 6 上）。 ⚠ 易混：未分辨格不是“无效应”的证据，而是此设计看不见；报告这件事本身是发现的一部分。
- **calibration sweep**（标定扫描）：先系统扫一遍错误权重，确定失败率何时可测。 → 本文里：t∈{86,88,90,92,95}：t≤90 在 1600 次抽取中零失败，t=92 给出约 3.1e-3，确认为主工作点。 ⚠ 易混：校准指选工作点，不是校准硬件或概率。
- **P1-prime (P1')**（P1′（主可测工作点））：(r,d,t)=(4801,45,92) 的主正式工作点；撇号表示它是早期筛选点的正式可测变体。 → 本文里：主结果 4.15/5.47/4.55 倍与全部轮次对照都在此测得：278 把密钥×3000 错误每臂。 ⚠ 易混：极易与 P1=(4801,45,84) 混；P1′ 不是 BIKE 生产参数，也不是 NIST 的比例缩放。
- **P1**（P1（筛选工作点））：(4801,45,84)：候选搜索期间的筛选工作点。 → 本文里：只出现在随机化一节，用于 BF30 负对照。 ⚠ 易混：永远是一号下标，不等于 P1′。
- **P2**（P2（迁移点））：(3001,37,66)：独立标定的迁移点，C0 在此同样可测。 → 本文里：冻结的 +2 偏移不经调参迁移到此（RR 1.95–3.21）；预注册的扩大确认（50 把重生成密钥）也在此。 ⚠ 易混：P2 上有两个实验（30 把迁移与 50 把确认），C0 失败率不同，论文警告不可混。
