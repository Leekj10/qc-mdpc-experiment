\subsection{压力构造与生产尺度证据}\label{sec:boundary}

压力实例让注入错误与近码字恰好交叠 $\kappa$ 个位置。在低于块行重的交叠处偏移仍有益：对均匀构造 RR 为 3.54 [2.41, 6.00]，在 $\kappa=12$ 处为 4.75 [2.00, 19.0]。在 $\kappa=46$ 处基线崩溃：C0 在 85.31\% 的样本上失败，FRO-2 为 86.50\%，RR 0.986 [0.981, 0.991]，位于有害一侧。在 $\kappa=60$ 处两个变体对 40{,}000 个样本无一译码成功。这些绝对率以允许该构造的密钥池为条件；「捕获倾向」描述的是构造，不是已证明的捕获事件。图~\ref{fig:scope}(b,c) 汇总该边界。

近码字感知步骤把标签与结果分开。在 $\kappa=46$ 处它在 74.2\% 的样本上触发，把残余失败从 85.31\% 降到 11.07\%；在 $\kappa=60$ 处信号消失（0.76\%）。在 $P_1'$ 处该监视器完全惰性：零触发，失败计数 282 / 372 / 141 与平均迭代 4.312 / 4.511 / 4.206 均不变。因此压力族在块行重之外改变性质；浅交叠条件不构成捕获保证。

在生产块 $(r,d)=(12323,71)$ 处，朴素失败率不可触及。重量为 134 时，两个变体在 32{,}000 次译码中都记录零失败，rule-of-three 上界为 $9.4\times10^{-5}$，这是本样本的测量地板，不是最坏情况保证。只剩决策余量与收敛代价：$+2$ 把每次译码的错误翻转从 13.8 压到 2.3，同时推迟 25.5 个正确翻转；平均收敛为 2.446 对 2.054。\label{sec:production}

把重量抬到 $t^\ast=172$（比生产重量高 28\%）打开一条陡带：170 处 $1.67\times10^{-4}$，172 处 $2.17\times10^{-3}$，175 处 $1.5\times10^{-2}$，180 处 $1.39\times10^{-1}$。在该重量下窗口在 32 把密钥、每把 1{,}500 条配对错误上复现（表~\ref{tab:added}）：FRO-2 给出 RR 4.48 [2.97, 7.25]，FRONEG 为 0.162 [0.119, 0.209]。

在原生 Level-1 $(12323,71,134)$ 上，动态距离留出在偏移 0、2、4 处对两个变体均记录零失败；唯一可测信号是收敛成本。在这些偏移处，两轮收敛率在 RAND 下分别为 96.0\%、68.4\% 与 2.2\%，在 TYPE-I 下分别为 91.7\%、60.2\% 与 1.5\%，在 NCW 下分别为 93.6\%、62.3\% 与 2.0\%，每格 1{,}000{,}000 次试验。

CPA-128 预设 $(10163,71)$ 是离生产最近的一次接近。带在 $t=138$ 与 $t=142$ 之间打开；重量 140 比生产高约 4\%，C0 的 DFR 为 $8.38\times10^{-4}$；160{,}000 次配对试验中，FRO-2 给出 RR 4.96 [3.68, 7.19]，FRONEG 为 0.177 [0.148, 0.210]（表~\ref{tab:added}）。这一点是邻近性检查：它检验窗口是否在生产附近仍然存在，而不是测量 CCA 裕度。

该偏移在主工作点 $(4801,45,92)$ 的配对动态距离 C 参考中的代价很小：每变体 500{,}000 次译码、20 轮预算下，C0 每秒 7{,}134.4 次译码、平均 4.191 次迭代，FRO-2 为 6{,}563.2 次、4.471 次（迭代比 1.067，吞吐比 1.087），在该点约付出 7--9\% 的墙钟时间（按吞吐计 8.7\%）。公布 Level-1 常数与该点不匹配的 GRAY\_BGF 每次译码花 13.2 次迭代，并在 47.9\% 的运行上耗尽预算。这些是单平台的最佳计时。在已测的高交叠压力下，改善消失或反向；在生产重量下，当前样本无法解析出 DFR 收益。在生产块尺寸上，错误重量一经抬高，窗口即复现。

\subsection{现代译码器定位}\label{sec:modern}

表~\ref{tab:modern} 把窗口与更强的译码器比较。匹配条件中的失败计数为：RAND 下 282 / 68 / 83 / 287，TYPE-I 下 372 / 68 / 94 / 391，NCW-shallow 下 141 / 31 / 58 / 84，依次对应 C0、FRO-2、BIKE-Flip 与 BGF-C3。

BIKE-Flip 使用规范自身的阈值公式与 A.2.4 常数；其 DFR 在每个条件中都落在 C0 与 FRO-2 之间（表~\ref{tab:modern}）。对 FRO-2 的 RAND 对比未分辨（精确 McNemar $p=0.23$）；TYPE-I 与 NCW-shallow 在 $0.0292$ 与 $0.00244$ 上给出名义分离，偏向 FRO-2。有一处不对称有利于对照方：BIKE-Flip 在我们的 20 轮预算下运行，而规范在七轮停止。

在抬高重量处，两个 BIKE-Flip 配置分别失败 28 与 13 次，FRO-2 为 21 次（$p=0.32$ 与 $0.18$）；切线拟合 BGF 失败 63 次，C0 为 94 次（$p=0.0125$）。公布仿射常数搬不到该重量（94.6\% 失败）；在七次迭代下配置退化到 $1.10\times10^{-2}$ 与 $1.84\times10^{-2}$，为 C0 的六倍与九倍。

BGF-C3 对 C0 的 RR 为 0.983 [0.836, 1.156]、0.951 [0.837, 1.086] 与 1.679 [1.362, 2.111]，所以 RAND 与 TYPE-I 下与 C0 统计不可分辨，只有 NCW-shallow 给出名义分离，偏向 BGF-C3。它用 5.28、5.46、5.16 次迭代，C0 为 4.31、4.51、4.21 次，约 22\% 的迭代成本。若喂入公布的 Level-1 常数而非 $d=45$ 处推导的常数，BGF 在 38--60\% 的译码上失败，这是常数错配边界。Backflip 仍强于本文测试的任何调度。在所测条件下，FRO-2 与规范译码器处于相近性能范围，但并不支配更强的译码器。这些 McNemar 检验把实例视为独立；它们是边际的，没有按密钥聚类或做多重校正。我们只把它们读作名义分离，而不是已确认的优势。
