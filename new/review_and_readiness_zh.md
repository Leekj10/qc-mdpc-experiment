# SCI 二区/三区标准审稿报告

## 总体判断

该研究已经具备一篇**稳健的 SCI 三区论文**所需的主要证据链，并具备冲击**部分 SCI 二区期刊**的基础，但目前不应表述为“达到顶刊科学贡献水平”。最强之处不是 FRO-2 的算法复杂度，而是实验设计的完整性：同实例配对、按密钥分层、全密钥划分、预设门控、纯新密钥复核、聚类自助法、第二参数点迁移、机制测量、阴性对照和明确的失效边界。最主要的二区风险是算法创新幅度较小，主结果位于人为标定的可测压力点，而非 BIKE 原生安全参数的可分辨 DFR 区间。

**建议审稿结论：Major Revision / Borderline。** 对一般密码工程、编码与信息安全交叉方向的三区期刊，新稿经作者信息和归档核验后可进入投稿准备；对强调密码学新颖性或理论保证的二区期刊，建议至少补充一项独立外部验证或理论分析。

## 核心贡献与证据强度

1. **最小干预清晰。** FRO-2 仅在第一轮将 CLASSIC 阈值提高 2，后续轮完全不变，便于归因和实现。
2. **主结果规模充分。** 278 把密钥、每把 3,000 个错误、每臂 834,000 个配对样本；RAND、TYPE-I 与浅层 NCW 控制三组的 C0/FRO-2 风险比分别为 4.15、5.47、4.55。
3. **密钥层推断合理。** 95% 区间以密钥为 cluster 重采样，三组均排除 1；逐密钥符号检验和配对 McNemar 检验方向一致。
4. **选择偏倚处理较好。** 212 把未接触任何中期决策的 pure-fresh 密钥仍复现结果，最差组门控改善从 0.679 增至 0.687 log10。
5. **机制证据不是仅靠失败分类。** 真错误支持的诊断测量显示，错误首轮翻转由 8.01-8.95 降至 0.84-0.99，约 9 倍下降；首轮后残余错误反而增加 5.16-6.09，说明作用来自避免错误注入并由后续轮恢复，而非首轮立即清除更多错误。
6. **外推边界被主动测试。** 第二参数点冻结偏置后仍有 1.95-3.21 倍改善；但当 $\kappa>d$ 进入真正近码字捕获时，FRO-2 不再受益，$\kappa=60$ 时两臂均 100% 失败。
7. **阴性结果完整。** 阈值随机化在边缘调度上导致显著恶化，在 CLASSIC 上中性偏负，正式筛选未选出 CPS 变体。

## 主要问题

### 1. 算法新颖性偏增量，是二区审稿的首要风险

“第一轮提高阈值”与 BIKE-Flip 的首轮保守思想存在明显概念邻近。本文的差异在于 CLASSIC 基座、整数单偏置、按最差条件上界选模、完整的密钥聚类实验和边界分析，而不在于提出了全新的译码范式。投稿时必须把贡献定位为**可复现的因果消融与条件风险研究**，避免使用 novel decoder、optimal 或 state-of-the-art 等表述。

**建议补强：** 推导首轮错误翻转概率随阈值偏置变化的近似式，或将已有短轮次 DFR 计数模型扩展到“首轮偏置、后续恢复”的至少一个可验证命题。理论触点会显著提高二区可接受度。

### 2. 主实验是可测压力点，不是生产安全点

$(4801,45,92)$ 与 $(3001,37,66)$ 都经过标定以制造 $10^{-4}$ 到 $10^{-3}$ 的可测 DFR。它们适合做机制研究，但不能证明 BIKE 目标 DFR 的改善。Level-1 的九百万次零失败只给出每格 $3/N$ 上界，不能比较三个偏置的真实尾部。

**建议补强：** 增加更接近原生参数、但能通过重要抽样或解析外推分辨尾部的实验；或者明确把论文投向“decoder behavior/experimental methodology”而非“BIKE security improvement”。

### 3. 条件组的外部有效性不均衡

RAND 是主外推对象；TYPE-I δ=12 是极罕见的对抗压力探针；NCW 组同时改变密钥接纳和错误构造，且 $\kappa=12<d$，不构成捕获。原始 H1 设定的 P90-P10 至少 3 log10 异质性门槛未达到，实测仅 0.40-0.48 log10。

**建议补强：** 增加真正 gathering 密钥族，或在新的随机密钥大样本中验证结构统计量与条件 DFR 的连续关系。正文必须如新稿一样明确报告 H1 未达，不能只报告干预成功。

### 4. 比较基线需要保持公平语境

scaled point 上的 BIKE-Flip 参数由规范公式外推，处于 out-of-tuning 状态；Backflip 使用动态真错误距离语义和更大状态/预算。FRO-2 在 scaled point 的优势不能写成对已发布解码器的普遍胜出。

**建议补强：** 把比较分成“同语义同预算”与“生产/参考实现”两层；报告运行时间、迭代分布、状态复杂度和常数时间实现影响，而不仅是 DFR。

### 5. 部分补充实验的密钥数偏少

机制、捕获、预算和密钥族分析每格多为 15-30 把密钥。它们足以支持方向与边界，但不适合承担主结论。稀疏格中 bootstrap 出现 treatment 零失败重采样，风险比区间会很宽或非有限。

**建议补强：** 保留绝对 DFR 差作为共同稳健指标；对关键补充分析扩大到至少 50-100 把密钥，或明确标为探索性/敏感性分析。

## 期刊层级判断

### SCI 三区

当前科学内容基本达到。推荐面向编码、通信安全、密码工程、可靠性实验类期刊。投稿前必须完成作者信息、硬件环境、Zenodo 最终快照与引用 DOI 核验，并在 cover letter 中突出实验协议与机制证据，而非夸大算法突破。

### SCI 二区

目前属于“有机会但不稳”。若目标期刊重视严谨实验、可复现性和负结果，现有工作可能进入外审；若期刊强调密码学理论或 SOTA 译码性能，创新性与原生参数证据不足。最有效的升级路径依次是：

1. 增加理论或半解析解释，并用实验验证其预测；
2. 增加外部团队的盲复现；
3. 增加 gathering 密钥或更自然的连续结构指标；
4. 在匹配语义、预算和实现成本下扩大现代译码器比较；
5. 补充常数时间与侧信道层面的工程评估。

## 本轮升级后的结论

### 与 BIKE 弱密钥论文的再对照

Nosouhi 等人的 *Weak-Key Analysis for BIKE Post-Quantum Key Encapsulation Mechanism* 已纳入相关工作（IEEE TIFS 18:2160--2174, 2023, DOI:10.1109/TIFS.2023.3264153）。该文的主线是 BIKE 实现、弱密钥对平均 DFR/IND-CCA 风险的影响，以及 key-check 机制；本文的主线是给定密钥下的译码调度、首轮机制和失败边界。两者问题不同，本文不应把 FRO-2 描述为弱密钥检测器或 BIKE 安全证明。

本轮再审还确认了三个需要明确写入投稿版本的项目：正文应保留一个最小但可执行的 FRO-2 配对译码伪代码；摘要应控制在常见 200--250 个英文词左右并减少置信区间细节；Python/C 结果应称为“跨实现复核”，不能称为“独立实验室复现”。具体对照和术语定义见 `comparison_with_bike_weakkey_zh.md` 与 `reproducibility_terms_zh.md`。

本轮修订将文章主线由“单一阈值改动的效果”提升为“结构化弱密钥风险下的首轮稳定化机制及其边界”。新增内容包括：

- 局部条件二项尾概率模型，明确提出错误翻转尾部应比正确翻转尾部更快下降的可证伪预测；
- 独立代码路径与 C 参考实现的跨实现复核，并明确它不是独立实验室复现；
- 固定均匀错误下的三类密钥族比较，新增 gathering-adjacent proxy，同时明确其不是文献中的精确 gathering 类；
- 对 C0、FRO-2、BF-Max、BIKE-Flip 和 Backflip 的分层、公平性标注，区分 tuned、out-of-tuning、static semantics 和 dynamic semantics；
- 在最终表 3 中把 BF-Max 明确降格为小样本探索性 Level-1 探针，并因调参与载体不匹配而不对 BGF 作正式排名；
- 现代译码器与跨实现复核结果的紧凑汇总表，避免用额外图表重复同一信息。

更新后的判断：SCI 三区投稿准备度进一步提高；SCI 二区仍建议在投稿前补充未接触搜索结果的外部实验室复现、精确 gathering-key 生成器、第三个独立参数点，以及常数时间/时序泄露评估。现有数据已经能够支持“跨实现复核”和“gathering 相关结构代理”这两个较窄结论，但不能支持“精确 gathering 防御”或“普适生产优势”。

图表数量保持为 4 张主图，新增 2 张结果表（总计 3 张核心表），与 5,000--6,000 字的完整实验论文相称。当前没有证据表明需要再增加主图；新增实验若未来产生新的变量关系，再单独考虑补充图。
